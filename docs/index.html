🚀 AstraCore

A Proxmox-powered homelab for virtualization, Docker workloads, and distributed systems

🧠 Overview

AstraCore is a sci-fi inspired homelab cluster designed to explore modern infrastructure, combining virtualization, automation, and containerised workloads into a modular platform.

⚙️ Core Stack

Virtualization

  • Proxmox VE
  • Multi-node cluster

Containers

  • Docker workloads
  • Service isolation

Storage

  • TrueNAS (NFS)
  • Centralised data layer

Networking

  • Reverse proxy
  • Remote access

⚙️ Phase 1 — Current Build

Active testing using distributed hardware.

  • 10-node ThinkCentre cluster (M73 / M93)
  • Proxmox across multiple nodes
  • Docker workloads within VMs
  • Distributed compute + service segmentation

🚧 Phase 2 — AstraCore V2

Post-move redesign into a centralised, rack-based environment.

  • Dell PowerEdge R610
  • 12-bay TrueNAS storage system
  • Cisco managed switch
  • Sophos XG firewall
  • VLAN segmentation + enterprise networking

🎯 Project Goals

  • Learn clustering and distributed systems
  • Build production-style infrastructure
  • Improve performance and reliability
  • Create a scalable homelab platform
