## Overview

AstraCore is a highly available, self-hosted homelab infrastructure designed for learning, privacy, and automation. It provides a resilient foundation for running personal services, managing IoT devices, and experimenting with local LLMs, fully detached from public cloud dependencies.

## Phase 1: Distributed Cluster

The current hardware topology relies on low-power, high-efficiency nodes clustered via Proxmox VE.

Hardware Nodes

  • Node 01 (Compute): Mini PC, Intel i5 12th Gen, 64GB RAM, 2TB NVMe
  • Node 02 (Storage): NAS, Intel Celeron, 16GB RAM, 32TB HDD Pool
  • Node 03 (Edge): Raspberry Pi 4, 8GB RAM, PoE+

Infrastructure Stack

  • Virtualization: Proxmox VE (High Availability Cluster)
  • Containerization: Docker / Docker Swarm
  • Storage: TrueNAS SCALE, ZFS datasets, NFS/SMB shares

## Hosted Services

Core applications managed via Docker and orchestrated across the cluster.

[ Networking & Security ]

  • Pi-hole: Network-wide ad blocking and local DNS.
  • Tailscale: Zero-trust mesh VPN for remote access.
  • Nginx Proxy Manager: Reverse proxy with automated SSL.

[ Automation & IoT ]

  • Home Assistant: Local smart home control and automations.
  • Node-RED: Flow-based programming for complex logic.
  • Mosquitto: MQTT broker for IoT device telemetry.

[ Media & Storage ]

  • Jellyfin: Self-hosted media streaming server.
  • Nextcloud: Personal file sync and share.
  • Immich: 🚧 Beta AI-powered photo backup.

[ Monitoring & Dev ]

  • Uptime Kuma: Uptime monitoring and alerting.
  • Grafana: Infrastructure metric visualization.
  • Gitea: Lightweight self-hosted git service.

[ AI & Local LLM ]

  • Ollama: Local model runner (Llama3, Mistral).
  • Open WebUI: 🚧 Setup ChatGPT-like interface.

[ Infrastructure & Utils ]

  • Portainer: Container management UI.
  • Watchtower: Automated Docker image updates.
  • Vaultwarden: Bitwarden-compatible password manager.

## Phase 2: AstraCore V2 ⏳ Planned

Future upgrades focusing on high-availability and dedicated AI acceleration.

  • Migrate Docker Swarm workloads to a lightweight Kubernetes (K3s) cluster.
  • Integrate dedicated GPU node (Nvidia RTX A4000) for faster local LLM inference.
  • Implement strict VLAN isolation for IoT devices vs. trusted client network.
  • Automated off-site backups via Restic to Backblaze B2.
